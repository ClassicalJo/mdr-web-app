# Ritual Revamp

My Daily Ritual — Home Page Redesign

We want to redesign and improve the existing My Daily Ritual website:

https://www.mydailyritual.app/

For this first step, only work on the Home page.

Main objective

Create a polished, modern and production-like version of the current My Daily Ritual homepage.

This is NOT intended to be a static mockup or design concept. It should be a fully functional, responsive website page with working navigation, buttons, links, animations/interactions where appropriate, and reusable components.

The goal is to improve the existing website while preserving its existing brand identity.

Important: preserve the existing brand

Use the current My Daily Ritual website as the primary visual and content reference.

Do NOT completely redesign the brand or introduce a new visual identity.

Preserve:

The existing colour palette

The overall warm, wellness-focused aesthetic

The existing photography and app screenshots where possible

The My Daily Ritual logo/branding

The general tone of the existing website

The existing messaging and positioning

However, improve the presentation, spacing, hierarchy, typography, responsiveness and overall user experience.

The result should feel like a more polished and premium evolution of the existing website, not a completely different website.

Home page structure

Keep the main content currently present on the website, but reorganise and improve it where it makes sense.

1. Header / Navigation

Create a clean, modern navigation bar.

Include:

My Daily Ritual logo

Home

Marketplace

Contact

Privacy Policy

A clear CTA to download the app

The navigation should be responsive.

On mobile, use a functional hamburger menu.

The header can become sticky while scrolling if this improves the experience.

Marketplace should link to a separate Marketplace page, which will be implemented later.

2. Hero section

Create a stronger and more visually impactful hero section.

Keep the current My Daily Ritual messaging and positioning, but improve the visual hierarchy.

The hero should communicate immediately:

What My Daily Ritual is

That it combines wellness, habits and productivity

That it helps users create meaningful daily rituals

Include:

Strong headline

Supporting text

Primary CTA to download the app

App Store button

Google Play button

High-quality existing My Daily Ritual imagery / app screenshots

The hero should feel premium, calm and aspirational rather than overly corporate.

3. "Your Ultimate Self-Care Toolkit"

Keep this section from the current website, but improve its presentation.

The current website communicates that My Daily Ritual combines mindset, planning, habits and wellness in one place.

Present these concepts in a visually engaging way using cards, icons, imagery or subtle animations.

The section should quickly communicate why the app is different from a basic habit tracker.

4. Why You'll Love My Daily Ritual

Preserve the current concepts:

All-in-One Toolkit

Designed to Be Used

Your Daily Flow, Sorted

Instant Feel-Good Dopamine

Fresh Start Every Day

Improve the visual presentation.

Use a clean card/grid layout with subtle hover states or animations.

Do not overdo animations.

5. Core wellness/productivity areas

Keep the existing concepts:

Morning Rituals

Gratitude, mantras and gentle movement.

Productivity Tools

To-do lists, goal setting and progress tracking.

Wellness Practices

Breathwork, stretching, meditation and sleep sounds.

Evening Reflection

Journaling prompts and routines for winding down.

Create a visually attractive section showing these four areas.

Use the existing app imagery wherever possible.

6. What's Inside

Keep the existing app screenshots from the current website.

Present them in a much more polished way.

The current website already shows examples of:

Daily rituals such as Gratitude, Mantra and Meditation

Yoga / movement content

Habit and mood tracking

Progress tracking

Use these existing images rather than inventing unrelated visuals.

The screenshots should feel integrated into the page rather than simply displayed one after another.

7. Testimonials

Keep the existing testimonials/reviews from the current website.

Improve the presentation with:

A clean testimonial carousel or card layout

Star ratings where appropriate

User names where currently available

Subtle transitions

The carousel should actually work.

Do not invent additional testimonials.

8. Download / CTA section

Create a strong call-to-action encouraging visitors to download My Daily Ritual.

Use messaging around:

Starting a daily ritual

Building healthy habits

Creating sustainable routines

Include:

App Store button

Google Play button

Buttons should be functional links. If the exact store URLs are not available yet, use clearly defined placeholder URLs/constants so they can easily be replaced later.

9. About / The Creation of My Daily Ritual

Keep the existing "The Creation Of My Daily Ritual" section.

Preserve the story about Liv and the philosophy behind the app.

Improve the visual presentation and hierarchy.

Use the existing imagery.

The section should communicate that My Daily Ritual was created from real-world experience helping women build sustainable habits and routines.

Do not substantially rewrite the story or invent new claims.

10. Final CTA / Footer

Finish the page with a strong but simple CTA.

Include:

My Daily Ritual branding

App download links

Navigation links

Marketplace

Contact

Privacy Policy

Copyright information

The footer should be clean and consistent with the existing brand.

Functionality requirements

This must be a real functional website, NOT a static visual mockup.

Implement:

Responsive design for desktop, tablet and mobile

Functional navigation

Functional mobile menu

Smooth scrolling where appropriate

Working CTA buttons

Working testimonial carousel if used

Hover/focus states

Appropriate subtle animations

Accessible buttons and links

Proper semantic HTML

Responsive images

Good loading behaviour

All interactions should actually work.

Do not create fake buttons that have no behaviour.

Technical requirements

Use:

React

TypeScript

Tailwind CSS

Component-based architecture

Keep the implementation clean and easy to maintain.

Create reusable components for repeated UI elements such as:

Header

Footer

CTA buttons

Feature cards

Testimonial cards

App download buttons

Section containers

Keep content/data separate from presentation where practical.

The website should be structured so that it can later be connected to a backend/API if needed.

For now, no backend is required.

Design direction

The final result should feel:

Warm

Premium

Modern

Calm

Feminine without being overly decorative

Wellness-focused

Trustworthy

Approachable

Avoid:

Generic SaaS aesthetics

Excessive gradients

Excessive animations

Overly futuristic UI

Dark/corporate styling

Completely changing the current My Daily Ritual visual identity

The existing website should be recognisable in the new version.

Most important requirement

Improve the existing My Daily Ritual website rather than replacing its identity.

The final page should look like the next, more polished version of the current website.
